# UX3 阅读、编辑与批注连续操作验收

基线：UX2 / PR #2 已合并（`16db676`）。本批不扩大跨块富文本编辑，先补齐受限操作反馈、未保存正文的批注参考和保存后继续批注。

1. 阅读中改一句话，已有批注仍可阅读/筛选，旧位置不着色、不跳转，不可写 YAML；正文和画布均未落盘。
2. 在 dirty 正文选择可映射文字，点击“保存正文并继续批注”；保存成功后用同一文档、完整候选快照和可见选区重新建立映射，再填写/保存批注。批注只写 YAML。
3. 保存冲突或失败保留正文恢复草稿与批注输入；更改正文后不搜索重复引文重接，要求显式重新选文。跨模式返回同一文档保留批注草稿；新打开文档清除本地批注表单，核心映射拒绝跨文档意图。
4. 源码中撤销已保存的阅读编辑成为 dirty，批注再次冻结；重做回保存版本恢复 clean。上述撤销/重做和模式切换不写三份文档文件。
5. Enter、多行粘贴、跨格式不安全编辑和不可编辑块提供原因与“在源码中继续”。原文不被隐式改写；被拒绝的已输入文本可复制恢复。普通单叶编辑和复制保持可用。
6. 1200×800、800×700、420×800 CSS px 检查批注面板、错误和源码入口。程序化组合事件仅作为逻辑回归，真实中文 IME、硬件 DPI 和安装全流程仍是 P0 待验收门槛。

核心门槛：BOM/CRLF/中文/emoji 与跨强调链接选区映射、重复选文不误贴、保存基线与撤销历史。窗口门槛：实际打包程序的连续任务、外部冲突、三文件 bytes/mtime 与现有阅读/结构/恢复回归。
