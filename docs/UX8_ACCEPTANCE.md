## 使用流程与文件边界

1. 打开含段落、嵌套列表、任务、表格和代码的 Markdown，进入卡片。摘要和全部正文采用同一纯文本投影。段落和块用空行分隔，列表逐项显示并保留层次、起始编号和任务状态，表格逐行显示并以 ` │ ` 分隔单元格，代码保留换行和缩进。摘要取前 160 个 Unicode 码点。准备结果继续由当前源码快照派生并通过原 Worker 投影复用。
2. 按标题查找。输入后显示匹配总数，包含折叠分支中的卡片。按 `Enter`、`Shift+Enter` 或上一项和下一项按钮，按 Markdown 源码顺序循环定位。每个同名结果有独立卡片身份，定位过程只更新窗口中的选择和视口。
3. 定位已收起的匹配项时，画布聚焦最近可见祖先，结果栏保留原匹配项并标明「已收起」。只有点击「展开并保存」才提交折叠状态。候选沿目标祖先链展开收起项，沿用当前保存模型中的视口、卡片坐标、尺寸和箭头标识。提交成功后才显示展开结果。定位展开后的目标属于窗口导航。
4. 选中章节卡片后点击「阅读本节」。阅读内容就绪时按当前文档和源码快照中的章节索引聚焦对应标题。标题文字重复时也能定位原卡片指向的章节。查找、定位、切换到阅读和返回卡片均属于只读导航。
5. 卡片正文采用保存的尺寸偏好及正文模式的最低高度。展开正文在卡片内滚动。空闲画布收起空状态条，保存、结构预览和导出成功提示约五秒后消退。待处理警告、进行中状态和错误继续显示。
6. 导出独立核验全图的卡片、箭头和标签范围。导出摘要保留空白边界，文本框按实际卡片宽度与 300 px 上限取较小值。若实际文字、标签或输出尺寸超出边界，停止保存并给出原因。

在隔离样本中，查找和阅读切换应保持 Markdown、批注 YAML 和画布 JSON 的字节及修改时间。显式展开仅更新画布 JSON。重开后，卡片尺寸、坐标、已存视口和箭头端点仍可与样本逐项比对。新文档自动整理也应在内存中完成。

## 适用范围

卡片文字按章节片段解析。原始 HTML 字面内容、元数据和定义正文会从投影中省略，同一片段内拒绝显示的 HTML 容器沿用阅读策略处理。如果原始 HTML 容器横跨 Markdown 解析器识别的根标题，后续片段中独立解析为 Markdown 段落的文字仍可能出现在卡片。原始 HTML `details` 中独立解析的 Markdown 块也按普通块投影。完整阅读入口使用原阅读渲染和折叠语义。

本记录覆盖 UX8 软件回归。UX7 真实中文 IME、QA1 物理设备和安装生命周期仍分别待验收。
