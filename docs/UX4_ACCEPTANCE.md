# UX4 画布精简与结构连续操作验收

基线：UX3 / PR #3 已合并（39f72eb）。依据设计评审的 UX4，保留既有源文本变换、批注映射、三文件事务和导出合同；没有新 schema、IPC 或依赖。

1. 三层嵌套、长正文和重复标题：父组边界轻于正文卡片；卡片不重复显示祖先路径，叶卡不显示零子章节计数，仅选中卡片显示常用动作。键盘选择器以章节序号及完整路径辨别重名。
2. 选中卡片显示正文显示/折叠/尺寸；选中箭头显示标签与删除。创建箭头单独折叠，标签草稿不与当前箭头标签混用，面板和专注开关保留输入。标签更新、删除、创建只允许画布 JSON 改变。
3. 拖动达到结构投放阈值或从属性区提出移动，在画布内显示操作摘要、标题级别、批注影响。源码差异默认折叠，可完整展开。取消恢复拖前坐标，Markdown/YAML/JSON 的 bytes 和 mtime 不变。
4. 预览期间冻结布局、折叠、箭头、视口写入和导出。切换模式或文档后到达的旧请求不得重新打开预览；其 token 显式取消。正文变化后旧预览不可确认，取消仍可达。
5. 确认只进入共享正文缓冲区，在画布内可撤销/重做，三份文件不落盘。只有顶栏显式保存提交结构和 sidecar 映射，保持 BOM/CRLF、重复引文身份、卡片 ID 与箭头端点。
6. 导出菜单说明包含完整场景、保留折叠状态，并显示可见卡片、关系、隐藏卡片及像素尺寸。预检复用实际导出几何（父子坐标、箭头曲线、标签），超限显示真实范围并禁用 PNG/JPG/PDF。现有主进程与渲染器继续检测实际输出限制。
7. 在 1200×800、800×700、420×800 CSS px 检查结构预览和超限导出。窄屏属性抽屉从顶部占满高度、独立滚动，确认/取消可见，无页面横向溢出。

结构样例（B 包含 C）：

~~~markdown
# A
## B
### C
# D
~~~

预览将 B 移到 D 之下；确认及撤销不保存，显式保存后：

~~~markdown
# A
# D
## B
### C
~~~

核心门槛：导出尺寸与实际边界一致，折叠计数不重复、无效几何拒绝、上限边界不裁切。打包门槛：新增 UX4 专项加既有阅读/源码/画布/事务恢复回归。真实 IME、硬件 DPI、安装卸载和大文档质量门槛仍属 P0 后续工作。
