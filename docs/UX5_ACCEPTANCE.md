# UX5 视觉一致性与窗口质量验收

基线：UX4 / PR #4 的 83e749b（开发开始时尚未合并）。本批独立分支叠加于 UX4，不自动合并前置 PR。

收尾核对 PR #4 已由仓库合并为 ce031bd，代码树与 83e749b 相同；本地分支已快进至最新 main，UX5 PR 直接以 main 为目标。

1. 外壳、阅读、源码、画布和批注共用字体、文字/边框/交互色及圆角规格；阅读正文 16 px，源码 13 px，辅助说明至少 12 px。批注颜色继续表示批注语义。
2. 鼠标选中与键盘焦点可区分；按钮、输入、目录、卡片和菜单拥有清晰焦点环。普通、警告、错误状态同时保留文字，不只依赖颜色；检验主要文字与背景对比。
3. 画布“更多”和“导出”互斥打开；Escape 关闭并返回触发器，方向键/Home/End 在可用动作间移动，Tab 离开及点击外部关闭；操作后的焦点可预测。所有纯呈现操作不写 Markdown/YAML/JSON。
4. 弹出菜单跟随触发器，并在窄窗口、滚动与缩放时限制于视口；超长内容可滚动。1200×800、800×700、420×800 CSS px，另检查 200% 页面缩放、高对比和减少动态效果。
5. 相同样本在阅读中保留语义表格/列表/代码和换行，在源码中显示完整字符；切换/查找/菜单/面板只改变呈现。新的视觉规则不得改变选文或文件保存边界。
6. 运行类型检查、单测、打包窗口回归和 Squirrel 构建；复测 1/1.25/1.5/2 DPR 的打包程序与既有性能样本，记录测量结果而不声称硬件 DPI 或大文档性能已闭合。

本切片不更改持久化格式、三文件事务、IPC 或依赖。真实中文 IME、跨显示器物理 DPI、干净机器安装/卸载残留和 Worker/虚拟化需要独立质量门槛，P0 不因视觉统一完成而宣布结束。
