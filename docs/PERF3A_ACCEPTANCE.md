# PERF3A：可取消的正文查找与索引复用

> 2026-10-16；基于已合并 PERF2 / PR #8（071bb59）。本批功能与数据边界通过。PERF3 按可运行切片推进，本批聚焦正文查找；正文分批渲染、源码输入及全量性能门槛仍待后续。

## 验收例子

1. 首次查找为当前阅读 DOM 建立索引，同一正文后续查询复用；长任务分段让出界面线程。连续输入只发布最新查询，清空、关闭、换文档和切模式立即使旧结果失效。
2. 查询期间显示正在查找，不闪出错误的“没有匹配”，上一项/下一项不跳到旧查询。失败不伪装成零结果。
3. DOM 正文编辑、取消编辑、details 开合和可见性属性改变后自动重新查找；不把搜索着色自身当成正文变更循环重建。
4. 保持跨强调/链接命中，禁止跨 br/块命中；排除 frontmatter、占位、隐藏正文和关闭 details。中文、emoji、组合字符、旗帜、重复文本及大小写匹配的 UTF-16 Range 必须正确，结果上限仍为 1000。
5. 搜索与导航不改变原文或 sidecar 的 bytes/mtime，不创建缺失 sidecar；批注、源码撤销、结构预览和全图导出回归保持。
6. 同机 1/5 MiB 各五次前后采样，比较首查/复查、无匹配、连续查询取消和最长帧间隔。单独记录极长单段落与可见性变化，不用纯核心耗时代替窗口结果。

## 设计复核

| Before | After | Why |
| --- | --- | --- |
| 每次查询重新遍历节点、读取全部文字几何并计算全文字素边界 | 按当前正文建立可失效索引；查询阶段仅核验候选匹配边界与几何 | 避免与结果数量无关的重复开销 |
| 查询同步完成，无法处理中途输入或关闭 | 分段执行并核验任务身份，旧任务取消 | 保持键盘输入与关闭操作可响应 |
| 折叠/正文变化不一定重新查询 | DOM 版本变化立即使旧结果失效并重查 | 不保留已经隐藏或改变的匹配 |

## 功能验证

- 类型检查和 283/283 单测通过。新增 3600 组 Unicode/字面查询组合（12×12×25）与完整字素分段参考算法对照，覆盖组合音标、旗帜、ZWJ 家庭 emoji、肤色修饰、印度文字、CRLF、大小写折叠和标点；另验证拒绝候选仍可中断、上限、UTF-16 范围与 5 MiB 长文本。
- 20 组生产打包窗口 E2E 通过：PERF3A、PERF2、PERF1、UX6A、UX1–UX5、B1、A6、A7.1、A7.2、A7.3b、A7.4、A7.5、A8.2–A8.5。覆盖语义阅读、批注、dirty、精确保存、结构预览/撤销、三文件恢复与完整场景导出。
- 专项实际检查 DOM 遍历计数：查询变化复用索引，着色不触发循环重建；折叠/隐藏/恢复/文字节点变化自动更新当前查询。补上嵌套块两侧不能拼成一个命中、任意关闭 details 祖先都隐藏内文的边界。
- 挂起异步步骤验证连续查询、关闭、换模式/文档后旧结果不能恢复；pending 禁用结果导航；异常明确显示失败，重新输入可恢复。空文件正确返回零项，75,000 组带肤色 emoji 的单段落可取消部分字素查询后找到尾部唯一词。
- 真实 Vite 开发服务专项通过；420×360 查找成功/失败状态与按钮可达，无整页横向溢出。只读操作检查现有三文件 bytes/mtime，缺失 sidecar 保持缺失；搜索不产生原生选区，不使用结果 Range 提交批注。
- UX4 原连续合成方向键在当前包两次停在前一项；上一批包同脚本通过。固定 focus emulation 后仍复现，最终在每次按键后等待 React Flow 选中节点投影的后续帧，再发送下一键，通过原选择、结构与三文件断言。没有修改画布产品行为或用赋值替代键盘验证。
- 收尾新增含 NUL 的查询跨原始 HTML br 的失败复现，改为独立索引项后重新 typecheck/package，PERF3A 与 A7.2 相关回归通过；此前 20 组回归的其他产品路径未再改变。最终性能样本来自这次修正后的包。

索引只在查找打开时保留，关闭即断开观察并清空节点/结果引用；单次几何或字素查询仍可能超过让出检查点，不承诺所有输入严格在 6 ms 内执行完毕。本批不引入 Markdown 虚拟化，首次正文 DOM、源码输入、200 可见卡片与大量批注仍待后续 PERF3 切片。

## 最终性能复测

同一 Windows 主机，1200×800 窗口、焦点仿真开启，无并行构建负载。基线为上一批 PERF2 安装包解出的应用，本批为最终生产 package；两版本 × 1/5 MiB × 各五次独立进程。1 MiB 样本为 1,058,744 字节、205 标题；5 MiB 为 5,288,903 字节、1024 标题。正文和 sidecar 使用隔离副本，测试前后核验 bytes/mtime。
