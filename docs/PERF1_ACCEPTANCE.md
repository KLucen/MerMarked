# PERF1 后台目录与阅读重复渲染验收

基于 UX5 的 802a00f；开始时 PR #5 未合并，独立切片不自动合并前置 PR。

收尾已核对 PR #5 合并为 348037b，代码树与 802a00f 相同，本批快进基线并直接面向 main。

1. 以同一打包程序脚本记录长文档打开、阅读查找、模式切换、源码输入到下一绘制帧和最长帧间隔；保留前后日志和样本规模，不将单次本机结果表述为普适性能保证。
2. 当前阅读树与编辑源文本完全相同时复用解析结果并线性映射 CRLF 偏移；其余源码目录由独立 Worker 解析。连续输入取消过期任务，文档切换/卸载/错误/超时释放 Worker。只发布当前文档和完整缓冲区快照对应的结果；更新中和失败时不提供旧偏移或旧章节结构操作。
3. 后台解析失败提供重试，完整源码、输入、撤销和显式保存保持可用。失败不降级为界面线程全文解析，不暴露原始异常。
4. 阅读 Markdown 内容和语义组件不变时，查找、面板、光标/状态及同内容草稿确认复用正文；内容变化必须重新渲染。既有 HTML 安全策略、选区、批注、重复引文与 BOM/CRLF 保持。
5. 模式、目录解析/失败/重试、查找及未保存编辑/撤销不写三份内容文件。章节变更仍必须通过既有完整源跨度预览、重新解析和显式保存。
6. 类型检查、针对性并发/解析测试、打包程序 Worker 成功/失败/过期回复与相关回归通过，生成安装包并记录产物。

此切片只迁移源码目录解析，不承诺全部阅读解析、可见正文搜索、DOM 渲染或画布布局已后台化。真实 IME、多显示器 DPI、安装卸载和完整大文档/虚拟化门槛仍独立待验收。
