# PERF2：首次阅读后台分析

> 2026-10-15；基于已合并 UX6A（main `fd24690`）。本切片功能与数据边界通过；整体性能和 P0 门槛仍进行中。

## 验收例子

1. 首次阅读在可取消 Worker 分析章节、选区映射与已知扩展，先显示加载状态；失败可重试或进入源码，不能退回界面线程同步分析。
2. 任务期间可换文档、切源码或卡片。离开终止任务；已排队的旧回复不能发布到另一个文档、模式或正文版本。pending/error 不开放旧目录偏移、旧锚点批注或阅读编辑。
3. 同一文档、完整正文及 BOM 元数据完全一致时复用已完成结果；源码目录可复用该章节投影。保存确认但正文未变不替换阅读 DOM。
4. BOM/CRLF、中文/emoji、重名标题、重复引文、复杂 Markdown 与 HTML 安全保持原语义。只读分析、取消、失败重试、查找和模式切换不改变 Markdown/YAML/JSON 的 bytes/mtime。
5. 保留 UX6A 输入保护、结构预览与精确保存约束；打包 Worker、开发服务、已有窗口回归及生产安装包都需要验证。

## 性能方法与边界

同机 Intel Core i9-14900HX、1200×800 CSS px、独立用户数据目录。基线来自上一批已验证的 UX6A nupkg，解压在 `out/qa/perf2-ux6a-baseline/lib/net45`，确认包含源码目录 Worker、尚无阅读分析 Worker。当前版来自本批生产 package；用相同脚本和 fixture，固定 CDP 焦点/可见性仿真，顺序执行，无并行构建或窗口测试。改造前后 1 MiB、5 MiB 各五次，共二十次；每次新进程、首次打开，随后查找、切源码、输入、撤销并核验三文件 bytes/mtime。

“首屏帧”是 renderer 观察到正文标题 DOM 后的双 requestAnimationFrame 代理值，不是像素呈现或全部批注核验完成。“命令完成”包含输入前等待、CDP 往返和状态轮询，必须与首屏帧分开。加载反馈从自动化动作准备开始计时，包含分发前等待；不能当作纯点击延迟。表中均为 **中位数 / 最差值，单位 ms**。

各阶段中位数不可直接相加。5 MiB 最差首屏仍为 4256 ms，说明仅减少解析不足以稳定达到目标；剩余调度等待与正文渲染需继续拆分。当前版 5 MiB 查找最长帧间隔最差 392 ms、切源码 300 ms、源码输入 108 ms。1 MiB 首屏时间近似持平，不能泛称所有文档打开均明显加速。

renderer 的 `Runtime.getHeapUsage.usedSize` 采样最大值：1 MiB 打开后 43 → 16 MiB、输入后 48 → 30 MiB；5 MiB 打开后 66 → 64 MiB、输入后 111 → 137 MiB。它受 GC 时机影响，不包含 Worker、主进程和进程 RSS，也不能证明总体内存降低。

另用 5,250,019 字节单段落压力样本，挂起真实 Worker 回复以稳定 pending 状态：最终打包测量从**实际 click 分发**到源码模式 DOM 5 ms、Worker 终止 4 ms；含分发前等待的测试命令为 3186 ms（模式 DOM 2794 ms）。两者不可混用。开发服务单次命令 408 ms、模式 DOM 12 ms。该测试证明待处理任务可取消，不能替代所有大文档、设备及绘制延迟的 200 ms 验收。

最终原始结果：`out/qa/perf1-perf2-stable-{before,after}-{1m,5m}-{1..5}.json`，汇总 `out/qa/perf2-stable-measurements.json`。更早单次与 `perf2-final-*` 为诊断中间数据，不用于最终对比。100 ms 加载、200 ms 模式响应和 PERF2+PERF3 整体预算尚未全部通过；下一批继续 PERF3，不能跳到界面扩展并宣称性能完成。

## 实际验收

- 类型检查与 280/280 单测通过；新增共享树只读投影、BOM/CRLF/中文/emoji/重复锚点、结构化克隆、过期回复/重复回复、取消、失败/重试和超时测试。
- 19 组生产打包窗口回归通过：PERF2、PERF1、UX6A、UX1–UX5、B1、A6、A7.1、A7.2、A7.3b、A7.4、A7.5、A8.2–A8.5。已有结构、持久化、冲突和完整导出断言均保留。
- PERF2 实际 Worker 覆盖加载/失败/重试、模式/文档/正文切换、排队旧回复、精确缓存、HTML 安全、三文件零写入与缺失 sidecar 不创建。真实 Vite 开发服务也通过；420×360 错误状态截图检查按钮可达，无横向溢出。
- 首版仅把三个调用移到 Worker，5 MiB 单次命令仍为 6124 ms；改为共用一次 AST 后再采样。没有用更快但不等价的正则替代 Markdown 解析。
- 部分旧窗口脚本在 Windows 遮挡下等待 rAF 挂起，加入 CDP focus emulation 后通过；保留原行为断言。UX3 等待编辑后正文时允许短暂加载状态；PERF1 的 Worker 注入仅针对源码目录，避免错误拦截新增阅读 Worker。
