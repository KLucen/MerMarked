# UX6A：未提交输入与离开保护

> 2026-10-15，当前切片已完成。基于已合并 PERF1 的 main `7736cd0`。本批只修复输入保护，不扩大 Markdown 编辑方言或调整 sidecar 保存合同。

## 验收例子

1. A 文档中新批注输入文字或选择标签，状态显示有未提交批注。打开/最近文件/拖入/重载前提供返回处理、明确放弃、取消；取消后文字、标签、原锚点和焦点可继续使用，三个内容文件不变。
2. 明确放弃后，文件选择取消或目标打开失败，仍保留 A 表单；只有成功切换才清除。明确放弃成功切换 B 后，A 不产生 YAML 写入，草稿不带入 B。
3. 编辑已有批注后切换阅读/源码/卡片，表单保留；换文档和关闭窗口同样保护。创建、重新定位另一条或切换编辑目标不能隐式覆盖已有表单。
4. 批注保存失败、保存仍在进行、正文块提交/IME 组合期间不允许离开造成输入丢失。保存失败保留表单；正文 dirty 仍冻结 sidecar，仍按原正文保存与冲突规则处理。
5. 未应用的多行粘贴输入计入状态并受到保护；返回源码继续不自动丢弃该文本。
6. 窗口关闭先核对 renderer 未提交输入，再执行已有主进程正文保存/放弃/取消；取消关闭或正文保存失败不清除本地表单。过期关闭许可、重复关闭和子 frame 回复不能绕过核验。

## 边界

确认离开本身不写 Markdown、批注 YAML 或画布 JSON；不将表单自动保存为批注，不承诺本次新增跨重启表单恢复。复用现有三文件保存/恢复和严格锚点规则。必要的关闭协调 IPC 只承载请求 ID、布尔许可和固定种类，不携带用户正文或任意文件路径。

## 验证计划

类型检查、全量核心测试；UX6A 真实打包窗口专项与 UX1/UX2/UX3/PERF1、源保存/恢复和画布结构相关回归；生产 package/make。自动化组合输入仅证明事件边界，不替代真实中文 IME。记录实际命令、失败、修复和未验证项后再提交、推送、创建 PR。
