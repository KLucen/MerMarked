## 用户操作与文件合同

文档菜单使用「创建已保存副本…」。同目录沿用 FILE1A 的原字节复制和附件共用。选择其他目录时，先审计已保存的原始 Markdown，再确认目的路径和实际会创建的正文 / 批注 / 画布文件。没有本地依赖才允许继续；取消预览不创建目标或暂存。

预检检查原始 CommonMark + GFM + frontmatter AST，遍历链接、图片和所有引用定义，包括未使用或重复的定义。空目标、页内锚点及合法的绝对 HTTP(S) / mailto 地址可保留；其他路径、协议、非法地址、任何原始 HTML 片段或注释、已知未支持扩展均保守拒绝。代码与 YAML 中的字面路径不作为资源。结果只显示类别和数量，不返回正文或 URL，不访问或下载附件。

允许的副本保留 Markdown、现有 YAML / JSON 的原始字节、旧 basis、待定位记录、卡片身份和箭头。不存在的 companion 不生成，不重新序列化，不切换文档、模式或最近文件。网络地址保留且不下载；当前阅读器不因该操作新增网络图片能力。不是离线资源包。

已有 dirty、表单、组合及待提交输入、在途操作和原文事务门槛保持。预览期间外部更改任一源文件、目标冲突或目的目录替换均拒绝，不覆盖文件。恢复旧快照仍明确返回 restored；未完成副本的确认中展示目的位置。

## 发布与恢复边界

默认 store 仍拒绝跨目录；只有显式的跨目录快照核验回调授权，才允许该分支。候选暂存在目的目录，目标父目录以 canonical path 和文件系统身份绑定，并在发布及恢复时重新核验。跨目录日志使用 v2；旧 v1 同目录日志继续按原合同恢复。

sidecar 优先、Markdown 最后独占发布；不删除或覆盖已发布目标。显式恢复从原 staging 快照补齐，外部修改、目录替换、非法日志或候选缺失保留为冲突。文件级 sync 不代表目录项断电持久性；日志前退出仍可能留下未发布 staging。单机不同目录的验证不能替代不同物理卷验收。
