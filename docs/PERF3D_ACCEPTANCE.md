# PERF3D：批注加载与规模验证

> 2026-10-17；基于已合并 PERF3C / PR #11（7f2eb7a）。本切片已验证，整体性能门槛仍未完成。

## 验收例子

1. 空批注列表仍核对 UTF-8、原始字节、BOM 和摘要，但不构建无用途的 Markdown 投影；不创建 sidecar。
2. 非空批注的选区和章节投影共享一次只读解析。当前摘要、重复引文、过期、歧义、碰撞、跨块及复杂标记的判定保持原有严格规则。
3. 实际窗口验证批注状态、着色、模式切换、查找、200 张可见卡片与大量批注；记录持续长任务而不提前宣称性能通过。
4. 新旧应用交替测量首屏、Worker 开始前等待、主进程事件循环间隔和已有输入/查找；验证三文件 bytes/mtime 不变。

## 设计复核

| Before | After | Why |
| --- | --- | --- |
| 空批注也在主进程解析全文两次 | 字节/摘要核验后按需要派生投影 | 避免空状态阻塞主进程和 Worker 加载 |
| 批注章节和选区各自解析 | 同一只读快照提供两种投影 | 保留源位置和歧义判定，减少重复计算 |
| 每条批注重新编码全文并扫描所有正文块 | 一个批次共用 UTF-8 字节及稀疏块边界索引，只检查可能包含锚点的块 | 减少主进程核验和界面着色的重复工作 |

## 诊断证据

旧版 5 MiB 空批注对照中，正常加载时主进程最大事件循环间隔约 1.9–2.4 秒，部分样本阅读 Worker 开始分析前等待约 1.9–2.0 秒。仅在测试中把批注加载延后 1.5 秒，Worker 开始前等待降至约 15–24 ms，主进程长任务仍存在。该干预支持批注同步解析阻挡 Worker 加载的判断；产品不通过延后批注加载隐藏问题。

仅做按需解析的中间版在 5 MiB / 500 条批注下，主进程批注加载仍约 13.9 秒，打开命令约 40.1 秒，返回阅读约 23.3 秒。进一步定位到每条锚点重复编码整篇原文、枚举所有块并重新计算前缀字节长度，因此本批增加批量索引。没有仅凭空批注样本宣布规模门槛通过。

索引只属于调用者传入的一份不可变 SelectionMap，按实际块边界建立稀疏 UTF-16 → UTF-8 检查点；不在代理对中间切分。候选仍经过相同完整字素、实体/转义、源码跨度及可见引文反向核验，重复候选仍拒绝。单条 API 和保存/事务检查保留原全文核验路径，不强制为每次调用建立批量索引。冻结输入、多个文档、重复块与超过 2000 个合法/篡改范围对照独立全文扫描 oracle。

规模样本使用已有的 20×10 网格位置，并通过实际“适应全图”确认 200 个节点都在视口内。初始自动布局是一条很长的平排，在最小缩放下只能看到 56 张，这次失败被保留为自动布局边界；网格测试不等同自动布局已解决。

## 最终测量口径

- 同机 Intel Core i9-14900HX，1200×800 CSS px；基线为 PERF3C 的打包程序，当前版为本批最终运行时代码。每轮交替旧版和新版，测试期间不并行运行构建或其他窗口测试。
- 空批注：1,058,744 字节 / 205 标题和 5,288,903 字节 / 1024 标题，各五对。规模样本：5,271,609 字节 / 200 标题 / 500 条独立短段落高亮，共三对；这是补充压力样本，不能替代更多真实文档和设备。
- 首屏是标题 DOM 出现后的两次 requestAnimationFrame，可能早于全部高亮。另记录从打开到首次观察到 500 个高亮 Range 的帧，避免把提前出现的正文误报为批注完成。
- 批注加载时间在主进程 IPC 外层记录，包含读取、解析与核验；主进程最大事件循环间隔覆盖整个场景。Worker 开始前等待包含启动、资源加载和调度，旧版这个时间有明显波动。
- 操作命令包含自动化分发、IPC 往返、条件轮询及后续帧等待，不是纯事件处理时间。输入处理段与事件至后续帧单独记录。renderer 堆读数未强制 GC，不含 main、Worker、GPU 或进程 RSS，不能视为应用峰值内存。
- 每次都验证 Markdown、批注 YAML 和画布 JSON 的字节及 mtime 未变；输入后通过撤销恢复，适应全图没有显式保存。

## 最终性能结果

## 后续边界

本批解决重复计算并补上规模证据，不扩大阅读编辑、Markdown 方言、保存格式或导出合同。非空批注仍有同步解析，200 张长卡片的切换和正文布局仍会产生长任务。下一批 PERF3E 优先分解卡片准备、提交与布局，补连续拖动和画布查找的规模测试，再按 UX6B → UX7 → UX8 → QA1 推进。

批注样本中的标记短且唯一，不代表所有重复长引文都有同等收益。真实中文 IME、物理多屏 DPI、干净 Windows 安装/升级/卸载尚未验收；不宣称 P0 或整体性能门槛完成。
