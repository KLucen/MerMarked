# MerMarkd 三模式职责与交互边界

> 2026-09-24 更新。本文定义阅读、编辑和卡片模式的职责、反馈和写入边界。A7.1 共同外壳与阅读交互、A7.2 阅读方言、安全 HTML 与可见正文查找均已完成并通过组合验收，实测记录见 `PROGRESS.md`。当前仍只有阅读模式可进入，编辑和卡片模式尚未实现；下一批为 A7.3a。

## 1. 共同外壳

下列能力属于应用外壳，不归某一种内容模式：

- 打开或拖入单个本地 Markdown、显示文件名与路径。
- 三模式切换、已检测到的外部修改提醒、未保存状态、冲突和恢复提示。主动文件监视是否引入由后续独立切片决定。
- 维护同一个 `DocumentSession`、当前章节和源位置，让模式切换能回到同一内容附近。
- 按当前模式分派查找命令：阅读模式查可见正文，编辑模式查找或替换源码，卡片模式查卡片。A7.2 已启用阅读正文查找；其余两类查找在对应模式开发切片启用。

模式切换本身不得写入 `.md`、批注 YAML 或画布 JSON。打开其他文件、重新载入或关闭窗口前，如存在未保存源码，必须先让用户明确处理。

## 2. 功能归属

| 能力 | 阅读模式 | 编辑模式 | 卡片模式 |
| --- | --- | --- | --- |
| 主要目的 | 阅读与形成结构化批注 | 查看和修改完整 Markdown 源码 | 查看与整理章节结构和额外关系 |
| 内容呈现 | 渲染 CommonMark + GFM 的语义结果，不显示结构语法 | 显示完整源文本，不渲染正文，不提供内嵌阅读预览 | 标题树生成卡片；正文摘要采用安全的阅读化渲染 |
| 定位反馈 | 当前章节、当前文字选区、当前批注 | 当前行、行列、源码选区、当前章节 | 当前卡片、连线、投放目标 |
| 查找 | 查可见正文 | 查找与替换原始源码 | 查卡片标题；正文搜索后置 |
| 阅读产出 | 高亮、便签、标签、跳回原文、重定位、人工重选、复制摘要 | 不创建或编辑阅读批注 | 首版不编辑批注，也不把便签混入卡片正文 |
| 修改 Markdown | 禁止 | 输入、粘贴、撤销、重做和显式保存 | 仅经差异预览确认的章节容纳关系变更 |
| 画布操作 | 无 | 无 | 拖动、缩放、折叠、全部展开/收起、连线和自动整理 |
| 导出 | 复制或以后另存阅读摘要 | 无独立导出 | 导出完整场景 PDF/JPG/PNG |
| 文件写入 | 批注操作只写 `*.md.annotations.yaml` | 输入先改内存缓冲区；显式保存才写 `.md` | 普通操作只写画布 JSON；结构变更按事务处理相关文件 |

任务列表复选框在阅读模式保持只读；改变 `[ ]` 或 `[x]` 必须进入编辑模式。卡片正文不提供直接富文本编辑；“编辑本节”跳到编辑模式的对应源码位置。

## 3. 阅读模式

### 3.1 无源码语法的阅读契约

“不显示 Markdown 语法”指受支持结构只呈现语义结果：

- 标题隐藏 `#` 或 Setext 下划线；目录用缩进和树关系表达层级，不显示 `H1/H2`。
- 强调、删除线、链接、图片、引用、列表、任务项和表格显示为相应的阅读组件。
- 表格不显示管线和对齐横线；列表显示排版后的项目符号或序号。
- 代码块显示代码内容，但隐藏围栏；代码内容中的 `#`、`*` 等仍是内容，应原样显示。
- 转义后本来就要显示的字符继续作为正文显示。
- frontmatter 是文档元数据，正文默认隐藏，可进入“文档信息”查看；编辑模式显示其完整源码。
- 所有非白名单原始 HTML 容器先在 `rehype-raw` 前替换为内部占位，再经过 HAST 元素策略和属性清洗，避免 HTML5 foster parenting 把容器内的文字或资源移到外部。允许列表内的语义内容可以呈现；普通未支持标签与 `script`、`style`、`iframe`、`object` 等危险内容分别显示克制占位，整棵子树都不作为普通正文提取。当前源码选区映射不解析原始 HTML，因此白名单 HTML 即使显示为可见文字也不能创建高亮或批注；原始 HTML 的 `h1`–`h6` 不进入由 Markdown 标题树生成的目录。详细白名单与属性合同见 `READER_DIALECT.md`。

首版契约限定为 CommonMark + GFM + YAML frontmatter。对能够无歧义识别的已知扩展给出一次文档级提示；其他内容按当前方言的普通文本规则处理，不宣称已经完成数学公式、Wiki Link、自定义 directive 等扩展渲染，也不承诺任意 Markdown 都能无语法显示。

sidecar 路径和文件 SHA 只可进入用户主动打开的“文档信息”。UTF-8 字节范围和 `sourceExact` 只可进入开发诊断，正常阅读界面和普通文档信息都不展示。原文只读、待定位数量等用户需要处理的状态可以保留，但应使用自然语言。

### 3.2 当前选区和当前章节反馈

阅读选区采用明确状态：

`无选区 → 正在核验 → 可操作 / 不支持 → 保存中 → 成功 / 失败`

- 鼠标拖选或键盘选择正文后即时核验；无选区时不显示整排高亮操作。
- 可操作选区保留系统选择反馈，并出现带可访问名称的 `role="toolbar"` 轻量操作条，显示可见引文或按 Unicode 字素计算的字符数，提供高亮色与“添加批注”。操作条出现时不自动夺取正文焦点；`Tab` 进入后使用方向键在工具项间移动，键盘焦点转移时用临时 CSS Highlight 保留原目标的视觉反馈。
- 不支持的跨块、复杂实体或歧义选区保留选择，并用用户能理解的原因说明，不显示源码和字节偏移，也不猜测或调整范围。
- `Escape` 按“人工重选 → 模态抽屉 → 普通选区”的优先级只处理一层状态；关闭选区工具后把焦点送回原正文块。人工重选取消时不写 sidecar。切换模式、重新载入或文档版本变化时清除旧选区。
- 选中边栏批注后，正文范围和对应记录同时显示当前状态，并使用下划线、边框或文字等非纯颜色反馈。
- 正文滚动、目录跳转和文内标题跳转都要同步当前章节；目录项使用 `aria-current="location"`，但不通过 live region 持续朗读滚动变化。
- 普通成功消息使用 `role="status"`，冲突或失败才使用 `role="alert"`。选区视觉状态可以在一个动画帧内更新；`aria-live="polite"` 在选择稳定后只播报状态变化，避免选择每增加一个字符就重复朗读。

本文把用户所说的“选择当前列”理解为对**当前文字选区或当前项目**的反馈，同时覆盖当前模式、当前章节和编辑器行列。产品目前不定义 GFM 表格整列选择；如需电子表格式整列操作，应另开功能切片。

### 3.3 阅读模式允许的写入

高亮、批注、标签、旧锚点审查和人工重选属于阅读模式。高亮、批注、标签、应用重定位及人工重选只写批注 YAML；仅审查候选不写文件；复制摘要只写剪贴板；阅读、查找、目录跳转和普通复制不写任何内容文件。阅读模式不得出现 Markdown 保存、源码格式化、章节级别修改、卡片连线或全图导出控件。

### 3.4 可见正文查找

- `Ctrl+F` 或外壳中的“查找正文”只搜索当前渲染的 `.markdown-body`。目录、文件信息、批注边栏、frontmatter、HTML 安全占位、隐藏内容和关闭的 `details` 不参与查找。
- 查询按字面量、Unicode 不区分大小写且只在完整字素边界匹配；结果不跨标题、段落、列表项、表格单元格或代码块，也不跨 `<br>`。同一查询最多保留 1000 项，达到上限时明确提示“仅显示前 1000 项”。
- 全部结果和当前结果分层显示，当前阅读块另有轮廓。上一项/下一项循环导航；关闭查找后焦点回到入口。
- 查找不改变正文原生选区，不把命中当成批注目标，也不写 Markdown、批注 YAML 或画布 JSON。编辑模式以后拥有独立的源码查找/替换，卡片模式以后拥有独立的卡片查找。

## 4. 编辑模式

- 使用纯源码编辑器显示完整 Markdown，包括 frontmatter、标题标记、链接目标、代码围栏和原始 HTML；保留并可编辑所有源码字符、空行、缩进和尾随空格。BOM、LF/CRLF 与尾换行状态显示在状态栏，空白符可视化作为可选开关。编辑模式不挂载阅读渲染器，也不提供左右分栏或内嵌预览。
- 提供源码查找/替换、目录跳到源码行、光标行列、选区字符数、撤销/重做、显式保存、重新载入和外部冲突处理。
- 语法着色可以帮助辨认源码，但不得隐藏、替换或富文本化任何字符。默认不自动格式化表格、不补空格、不更改标题级别。
- 编辑输入先进入内存缓冲区和单文档恢复草稿（A7.3a）。保存时使用当前会话派生的路径和预期磁盘摘要，保留 UTF-8 BOM、LF/CRLF、无尾换行及未参与编辑的字节；无操作保存必须保持文件摘要不变。跨 Markdown、YAML、JSON 的恢复事务属于 A8.1。
- 源码选区不弹出阅读高亮或批注工具。查看批注应切回阅读模式的相同章节。

编辑缓冲区未保存时，切到阅读模式只能显示明确标记的“未保存预览”；依赖已落盘摘要的批注新增、编辑、重定位和卡片结构写入暂停。保存成功并完成锚点核验后才恢复这些写入。第一版可把受影响旧锚点交给现有 A6 审查流程；不得沿用旧偏移。

切到卡片模式时可从当前缓冲区派生标为“未保存结构预览”的只读画面，只允许定位、平移和缩放；布局持久化、连线、结构操作和导出保持禁用，直到 Markdown 保存成功、章节 ID 完成核验且画布基线重新载入。

## 5. 卡片模式

- 每个可移动章节由同一标题树派生；卡片展示标题、阅读化摘要、直接子章节数量和关系状态。
- 普通拖动、缩放、折叠、全部展开/收起、连线、自动整理和导出不改 Markdown。
- 只有进入明确的“设为子章节/提升层级”命令、查看 Markdown 差异并确认后，才可产生源文本补丁。
- 当前卡片、当前连线和投放目标使用边框、标签与属性面板共同反馈，不只依赖颜色。
- PDF/JPG/PNG 导出属于卡片模式，范围是完整场景边界，不是当前屏幕截图。

## 6. 当前实现差距

截至 A7.2 完成基线，应用仍只有阅读模式，但 A7.1 已完成下列收口：

- `AppShell` 统一承载打开/拖入、文件状态、已检测到的原文变化、提示、模式入口和阅读查找入口，`ReaderView` 独立承载目录与阅读布局。
- 阅读入口以 `aria-current="page"` 表示当前模式；编辑与卡片入口禁用且明确显示“尚未开放”。这仍不等于三模式切换已经实现。
- 普通阅读界面已移除 `H1/H2`、sidecar 路径、UTF-8 范围、`sourceExact` 和原始 Markdown 片段。
- 正文选择会即时核验并在目标附近反馈；正文外新选择、重新载入或换文件会清除旧目标。手动滚动、目录与文内链接均同步当前章节。
- A7.2 已加入受控原始 HTML、未支持扩展提示和可见正文查找，并完成 HTML5 foster parenting 与批注加载错误信息边界的安全收口；验证记录见 `PROGRESS.md`。

仍未实现的边界是：

- 主进程没有 Markdown 保存 IPC、编辑缓冲区、dirty 状态或保存冲突流程。
- 卡片、画布 JSON、连线和导出尚未实现。

## 7. 调整后的开发顺序

为保持每批可运行且便于试用，A1–A6 的历史编号不变：

1. **A7.1 模式导航外壳与阅读交互收口（已实现）**：打开/拖入、文件名、重新载入、已检测到的外部变化和冲突状态已移入共享 Shell，没有新增主动文件监视；独立 `ReaderView` 已移除普通阅读界面的源码诊断和 `Hn`，并提供即时选区与滚动章节反馈。编辑与卡片入口继续禁用且明确“尚未开放”。
2. **A7.2 阅读方言与查找收口（已完成）**：CommonMark + GFM + frontmatter 阅读管线、原始 HTML 允许列表/占位策略、已知未支持扩展的文档级提示和可见正文查找已经实现并通过组合验证，首版阅读合同的实测证据记录在 `PROGRESS.md`。
3. **A7.3a 安全保存与单文档草稿原型（下一批）**：先在 `src/core` 和主进程证明 BOM、LF/CRLF、无尾换行、expected SHA、原子替换、外部冲突与单个 Markdown 崩溃草稿，不开放编辑界面。
4. **A7.3b 纯源码编辑模式**：接入纯源码编辑器、dirty、源码查找/替换、撤销/重做、行列、显式保存及未保存阅读/卡片预览限制。
5. **A7.4 编辑补丁到批注映射**：受影响锚点只在能证明时迁移，其余交给现有待定位审查；不依赖尚未实现的画布模型。
6. **A7.5 章节源码变换原型**：实现章节移动、级别调整、差异预览、重新解析、撤销和危险变换拒绝。
7. **A8.1 画布数据门槛**：先固定最小画布 schema 与稳定卡片 ID，用 JSON fixture 验证 Markdown、批注 YAML、画布 JSON 的跨文件中断恢复。
8. **A8.2 嵌套画布与关系持久化**：实现卡片嵌套、拖动、折叠、全部展开/收起、箭头、布局 JSON 与重开恢复；普通画布操作不改 `.md`，重名标题不得误连。
9. **A8.3 独立全图导出**：从已核验的画布场景生成 PDF/JPG/PNG，单独处理分页、分块和尺寸上限；视口外节点、中文、长卡片、箭头与标签不得被静默裁切。

每个子批次完成后停止，交付安装包和验收结果，等待用户试用反馈后再继续。

### A7.1 最低验收

- 打开/拖入、文件名、重新载入、已检测到的外部变化和冲突状态由共享 Shell 承担；阅读视图卸载后这些能力仍有单一状态来源，本批不增加主动文件监视。
- 当前已支持的标题、强调、链接、图片、引用、列表、表格和代码围栏不因重构重新泄露结构语法；HTML 与已知扩展的完整合同在 A7.2 验收。
- `selectionchange` 后在下一动画帧合并核验，正常验收 fixture 的可见反馈目标不迟于 100 ms；工具取得焦点后仍指向原选择；不支持选区有具体原因。
- 选区状态绑定当前 `documentEpoch` 与 `sourceSha256`；重新载入、换文件、源码版本变化或组件卸载会取消待执行回调并清除旧 `Range`。目录、工具条和边栏输入中的选择不会触发正文批注状态。
- 阅读界面不显示 `sourceExact`、字节偏移、`H1/H2` 或常驻 sidecar 路径。
- 目录点击、文内标题链接和手动滚动都更新当前章节；平滑滚动结束后稳定在目标章节，不在相邻目录项间抖动。当前模式、章节和批注均有非纯颜色反馈。
- 中文、英文、全角标点、emoji 和组合字符选区不截断；800×600 实际窗口、200% 缩放及 320 CSS px 模拟视口下页面根容器无横向溢出，宽表格与代码块仅在自身容器横向滚动，焦点、选区工具和错误原因不被局部滚动区域裁掉。实际窗口当前最小宽度仍为 800 px。
- `forced-colors` 下当前模式、章节、选区和批注仍可区分。
- `role="status"` 用于普通进度/成功，`role="alert"` 只用于冲突或失败；当前章节滚动不触发 live region 连续播报。
- 被动选区、无效选区、`Escape`、滚动和浏览模式入口前后，`.md` 与批注 YAML 摘要均不变；画布 JSON 若存在则摘要不变，不存在时不得创建。只有用户显式执行批注变更（新增、改色、编辑、删除、标签变更、应用重定位或人工重选）才允许写批注 YAML。
- 回归 A4–A6：有效选区仍写入正确锚点；人工重选的 `Escape` 优先；外部修改、待定位、只读 sidecar 和草稿门槛不能被即时状态绕过。

### A7.2 最低验收

- CommonMark、GFM 与 YAML frontmatter fixture 的语义 DOM 符合 `READER_DIALECT.md`；受支持结构不泄露结构标记，frontmatter 不进入正文或正文查找。
- 白名单原始 HTML 只保留允许的元素、属性和协议；所有非白名单容器在 `rehype-raw` 前屏蔽，普通未支持与危险内容分别只显示一个占位，子树中的文字、资源和事件不能因 HTML5 foster parenting 进入正文。允许显示的原始 HTML 选区不能误开可写批注操作。
- sidecar 读取、当前 Markdown 复核读取与 YAML 解析失败只向阅读界面返回稳定错误码和自然提示；`reason` 不含原始异常、`sourceExact`、字节范围或绝对路径。
