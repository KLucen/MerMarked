# MerMarkd

MerMarkd 是开发中的本地 Markdown 阅读与章节卡片软件。规划中的桌面应用提供源码编辑、排版阅读和按标题生成的卡片画布三种模式。

**当前状态：P0 阅读与批注原型。** 已可打开本地 `.md`、浏览排版正文与章节目录，并把可精确定位的选文保存为高亮或纯文本便签。便签支持无标签、选择已有标签或创建新标签，以及筛选、跳回原文、编辑和删除；宽窗口使用右侧边栏，窄窗口使用可收起抽屉。外部修改原文后，可审查并显式应用严格匹配的重定位候选，也可为其余待定位记录人工重新选择；批注可按当前标签筛选复制为 Markdown 阅读摘要。中英文混排表格、列表和长代码行已有可滚动的阅读布局。编辑模式、卡片模式、章节移动、三文件恢复和全图导出仍在后续批次。已完成什么、哪些能力通过实测，见[开发进度](docs/PROGRESS.md)。

## 试用阅读功能

在 Windows 上运行 `npm ci`，随后执行 `npm start`；也可执行 `npm run make`，安装 `out/make/squirrel.windows/x64/MerMarkd-0.1.0 Setup.exe`。点击“打开 Markdown”或按 `Ctrl+O` 选择 UTF-8 编码的 `.md` 文件。[阅读样本](tests/fixtures/reader/reading-features.md)包含目录、表格、任务列表、代码块和相对图片；[混排样本](tests/fixtures/reader/mixed-layout.md)可用于检查窄窗口的中英文表格、两位数列表和长代码行。宽表格与代码块可在各自区域内横向滚动。

可把单个 `.md` 拖到右上角“打开 Markdown”附近的区域。阅读时选中同一标题或段落中的文字，可以选择一种高亮颜色，也可以点击“添加批注”，保存为无标签便签、选择已有标签或同时创建新标签。批注边栏支持按标签筛选、跳回原文、编辑和删除；窄窗口可从“批注”按钮打开抽屉。同一精确选区已有高亮时，添加批注会把原记录转换为便签并保留其颜色，不生成重复锚点。展开“高亮记录”仍可跳回原文、改色或删除；关闭重开后恢复。当前原型仍有“检查选区定位”的源码诊断入口，A7.1 将把它移出普通阅读界面并改为即时、只显示可见文字的选区反馈。

原文在外部修改后，先重新载入文档。界面会把严格核验通过的候选列为“可安全重定位”，由用户点击应用后才写回 sidecar；删除、重复、上下文变化或当前阅读视图无法精确映射的记录继续待定位，可选择新文字后人工重新绑定。边栏的“复制摘要”按当前“全部 / 无标签 / 指定标签”筛选，把已定位记录按当前章节组织，并把待定位内容单独附后，复制为 Markdown 文本。

高亮、便签和标签写入原文同目录的 `<文件名>.md.annotations.yaml`。当前已实现的阅读模式以只读方式载入 `.md`；未来编辑模式只在用户显式保存时修改原文。无法精确映射的选区会被拒绝；源文件或 YAML 在审查期间再次变化时，应用会阻止覆盖并保留候选草稿。重定位不会用旧字节位置或章节名称猜测重复文本，也不会在用户确认前静默改写 sidecar。复制摘要只写入系统剪贴板，不修改 Markdown 或批注文件。

支持文档目录内的相对图片和 `http`、`https`、`mailto` 外链；相对 Markdown 文档链接暂不打开。未经转换的非 UTF-8 文件会显示错误提示。当前安装包未签名，仅供本机试用。

## 目标三种模式的边界

- **阅读模式**显示排版后的语义内容，不显示受支持结构的 `#`、强调符、链接目标、表格管线或代码围栏；高亮、批注、标签、阅读摘要与批注重定位都在此模式完成。
- **编辑模式**显示完整原始 Markdown，不进行正文渲染；输入、查找替换、撤销重做和显式保存只属于此模式。
- **卡片模式**显示标题派生的章节卡、折叠、箭头和画布；普通画布操作只改画布 sidecar，只有预览并确认的章节容纳关系才可修改 Markdown。

完整的选区反馈、模式切换和文件写入规则见[三模式职责与交互边界](docs/MODE_BOUNDARIES.md)。当前代码仍只有阅读模式；下一批先完成共享模式导航外壳和阅读交互反馈，后续再分别收口阅读方言、安全保存与纯源码编辑。

## 本地开发

首发开发环境为 Windows、Node.js 与 npm。执行 `npm ci` 安装锁定依赖，`npm start` 运行桌面应用，`npm test` 和 `npm run typecheck` 验证代码，`npm run make` 生成本地 Windows 测试安装包。若 Electron 下载因 GitHub 超时，可在执行构建的同一终端设置 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 后重试。最新验证结果以进度记录为准。
